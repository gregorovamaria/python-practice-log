
# Daily Python Projects

This repository contains solutions to practice problems inspired by the tasks
and exercises from various sources, e.g.:
- [Daily Python Projects](https://dailypythonprojects.substack.com/) by Ardit Sulce.
- [Leetcode](https://leetcode.com/problemset/)
- [Codewars](https://www.codewars.com/)


## Structure
The code is organized into three folders by difficulty level:

- `simple` – fundamental syntax and simple scripts, functions, error handling, or basic CLI patterns.
- `more-complex` – more practical, slightly larger scripts that resemble real use cases.

Each file is a small, self-contained script that solves a single problem.

Examples include:
- Simulating dice rolls and printing the result.
- Suggesting random self-care activities and printing the result.


## Goals

- Build consistent daily coding practice.
- Write clean, well-typed, and well-documented Python code.
- Gradually adopt professional patterns (docstring, type hints, CLI tools, etc.).
