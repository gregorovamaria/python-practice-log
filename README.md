
# Daily Python Projects

This repository contains solutions to practice problems inspired by the exercises from [Daily Python Projects](https://dailypythonprojects.substack.com/) by Ardit Sulce.


## Structure
The code is organized into three folders by difficulty level:

- `beginner` – fundamental syntax and simple scripts, functions, error handling, or basic CLI patterns.
- `real-world` – more practical, slightly larger scripts that resemble real use cases.

Each file is a small, self-contained script that solves a single problem.

Examples include:
- Simulating dice rolls and printing the result.
- Suggesting random self-care activities and printing the result.


## Goals

- Build consistent daily coding practice.
- Write clean, well-typed, and well-documented Python code.
- Gradually adopt professional patterns (docstrings, type hints, CLI tools, etc.).
